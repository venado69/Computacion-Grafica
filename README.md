## Descripción

En esta práctica se realizaron dos ejercicios utilizando OpenGL y transformaciones en 3D.

### Ejercicio 1 - Cohete espacial

Se creó un cohete utilizando diferentes figuras geométricas:

- Cilindro para el cuerpo principal.
- Cono para la punta.
- Esfera para la ventana.
- Pirámides para las aletas.
- Cubos para los motores.

Las figuras fueron colocadas mediante transformaciones de posición, rotación y escala.

### Ejercicio 2 - Unión de 8 pirámides

Se creó una figura formada por ocho pirámides cuadrangulares.

Cada pirámide contiene:

- Cara roja.
- Cara verde.
- Cara amarilla.
- Cara magenta.
- Base cuadrada azul.

Las pirámides fueron organizadas en cuatro pares alrededor de un punto central utilizando instancias y transformaciones.
